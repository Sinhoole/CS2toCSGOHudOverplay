# OverplayHUD

## 概要

CS2 では CS:GO 時代の HUD レイアウトが変更されています。本プロジェクトは、ゲーム画面の上に
全透過かつマウス透過のオーバーレイを重ね、スコアボード、所持金、体力とアーマー、弾薬、
キルストリーク表示、武器リストを CS:GO のレイアウトと外観で再描画します。

データの情報源は Valve が公式に提供する GSI（Game State Integration）インターフェースのみです。
ゲームプロセスがローカルポートへ JSON を POST し、本アプリケーションは受信と描画のみを行います。
ゲームメモリの読み取り、DLL の注入、レンダリングパイプラインへのフック、入力のシミュレートは
一切行いません。

> Faceit、ESEA、5E、B5 などのサードパーティ製アンチチートプラットフォームでの使用は推奨しません。
> これらの検出方針は VAC よりもはるかに厳しく、オーバーレイ自体が違反と見なされる可能性があります。

## 主な機能

**HUD モジュール**

| モジュール | 内容 |
|---|---|
| スコアボード | 画面上部中央。チームエンブレム、生存表示、スコア、ラウンドタイマー |
| 所持金 | 現在の残高。購入支出とキル報酬は追加行として表示 |
| 体力とアーマー | 下部バー。体力は 4 段階の状態に分類し、アーマーとヘルメットは個別に表示 |
| 弾薬とキルストリーク | 右下。キルストリークのスカルバッジ、装弾数と予備弾数 |
| 武器リスト | 右側の縦列。メイン武器、サブ武器、近接武器、グレネード、特殊装備 |

**通知とカスタマイズ**

- キル、マルチキル、死亡、アシスト、MVP の 5 種類のイベントでテキスト通知を表示します。同一フレーム内では 1 件のみ表示します。
- 任意の数のカスタムテキスト要素を追加でき、変数（体力、所持金、戦績、ラウンドなど）を挿入できます。
- 矩形、楕円、直線、フリーハンド曲線、テキストを描画できるツールを内蔵し、HUD 要素またはアイコンとして保存できます。

**外観と設定**

- 12 種類のフォントプリセットを内蔵し、任意のシステムフォントも指定できます。
- 各要素の位置、拡縮、回転、不透明度、グロー、縁取りを個別に調整できます。
- 詳細な外観設定として、登場・パルス・振動アニメーション、湾曲テキスト、ゲームパッドの振動に対応します。
- すべての設定項目にグラフィカルな設定画面を用意しており、変更は即時プレビューされます。

**その他の機能**

- CS2 のインストールディレクトリを自動検出し、GSI 設定とネイティブ HUD 無効化コマンドをワンクリックで書き込みます。
- 設定プロファイルのエクスポート、インポート、共有に対応します。

## ダウンロードとインストール

インストーラー版とポータブル版は、本リポジトリの **Releases** ページで公開しています。

| ファイル | 説明 |
|---|---|
| `OverplayHUD-x.y.z-setup.exe` | インストーラー版。スタートメニューとデスクトップにショートカットを作成します（推奨） |
| `OverplayHUD-x.y.z-portable.exe` | 単一ファイルのポータブル版。インストール不要 |

インストール手順：

1. アプリケーションを実行すると、システムトレイに OverplayHUD のアイコンが表示されます。
2. トレイアイコンを右クリックし、「安装 GSI 配置到 CS2」（GSI 設定を CS2 へインストール）を選択します。
3. CS2 を完全に終了し、再起動します。サーバーへの再接続では反映されません。
4. CS2 のビデオ設定で表示モードを「フルスクリーンウィンドウ」に設定します。排他フルスクリーンではオーバーレイが隠れます。
5. トレイアイコンを右クリックし、「设置」（設定）から外観を調整します。

> 設定画面の表示言語は現在中国語のみです。

## ソースからの実行

コードの変更や自前ビルドを目的とする場合の手順です。Node.js 18 以上と Windows が必要です。

### 1. GSI 設定のインストール

```bash
npm run install-cfg
```

CS2 のディレクトリを自動検出し、`gamestate_integration_overplayhud.cfg` を
`game/csgo/cfg` と `game/core/cfg` の両方へコピーします。CS2 には cfg ディレクトリが 2 つあり、
片方のみに配置した場合は反映されないことがあります。自動検出に失敗した場合は、
ゲームのパスを明示的に指定します。

```bash
node tools/install-cfg.mjs --game "D:\SteamLibrary\steamapps\common\Counter-Strike Global Offensive"
```

完了後、CS2 を完全に再起動する必要があります。

### 2. データ接続の確認

```bash
npm run verify
```

試合に入ると、ターミナルに毎秒 1 行のステータスが出力されます。
20 秒以内に出力がない場合は、トラブルシューティングの一覧が表示されます。

### 3. オーバーレイの起動

```bash
npm start        # 通常使用
npm run mock     # ゲームを起動せず、シミュレーションデータでプレビュー
```

## ネイティブ HUD の無効化

設定画面の「原生 HUD 命令」（ネイティブ HUD コマンド）ページから、以下のコマンドを
ワンクリックで CS2 へ書き込めます。手動で実行することも可能です。

```cfg
cl_draw_only_deathnotices 1          // クロスヘアとキルフィードのみ残す
cl_drawhud_force_radar 1             // レーダーを残す
cl_drawhud_force_teamid_overhead 1   // 味方の頭上マーカーを残す
bind alt toggle cl_drawhud_force_deathnotices 1 0
r_drawtracers_firstperson false      // 一人称のトレーサーを無効化
```

レーダーとキルフィードはゲーム本体の UI が描画します。GSI はローカルプレイヤーの
レーダー座標を提供しないため、この 2 項目はゲーム側に委ねています。

## 設定画面

起動時に設定画面が自動的に開きます。トレイメニューまたは `npm run settings` からも開けます。

ナビゲーションは 4 つのグループに分かれています。概要、基本設定、詳細設定、ツールとヘルプ。
外観パラメータはスライダーとカラーパレットで提供され、変更はオーバーレイへ即時反映されます。
問題がなければ保存をクリックします。保存していない変更はウィンドウを閉じた時点で破棄されます。

「リアルタイムプレビュー」機能では別ウィンドウを開き、シミュレーションデータで
詳細な外観設定を確認できます。現在の試合には影響せず、ゲーム入力も発生しません。

## 制限事項

GSI インターフェースには以下の本質的な制限があり、プログラム側で回避することはできません。

| 項目 | 説明 |
|---|---|
| レーダーとキルフィード | ゲーム本体が描画 |
| 生存人数 | ローカルプレイヤー視点では取得不可。既定では CT / T のラベルを表示し、観戦視点では実数を表示可能 |
| 味方・敵の情報 | 死亡後の観戦、GOTV、リプレイ時のみ提供 |
| キルイベントストリーム | データなし。通知は 2 つのスナップショット間のキル / デス / アシストの差分から推定 |
| ラウンドタイマー | ローカルクロックによる推算で、誤差は約 ±0.5 秒。観戦視点では公式データを使用するため誤差なし |

これらの制限は Valve が GSI で公開している範囲に起因するものであり、本実装の問題ではありません。

## セキュリティと互換性

- データは公式 GSI のみを情報源とし、`127.0.0.1` のみをリッスンします。外部へポートを公開しません。
- ゲームメモリの読み取り、DLL の注入、レンダリングフック、入力のシミュレートは行いません。
- 表示内容は、通常のプレイヤーが確認できる情報の範囲に限られます。
- CS2 の表示モードは「フルスクリーンウィンドウ」に設定する必要があります。
